# IEEE SB CEC — Landing Page

A landing page for the IEEE Student Branch, College of Engineering Chengannur (CEC), built as part of the web team volunteer call.

## Live Demo

[View Site](https://mytaskpage.netlify.app/)

## GitHub Repository

https://github.com/liya-royy/mytask

## Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Styling:** Tailwind CSS
* **Fonts:** Syne, DM Sans, Space Mono (Google Fonts)
* **Deployment:** Netlify

## Sections

* **Hero** — Branch intro, stats, CTA
* **About** — Mission, vision, core values
* **Events** — Rev-A-Thon 2.0, NAVIRA 2.0, LunarCAD 2.0, and more
* **Chapters** — IEEE societies at CEC
* **Timeline** — Branch history and milestones
* **Testimonials** — Member experiences
* **Footer** — Contact and social links

## Running Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Project Structure

```text
app/          → Next.js pages and global styles
components/   → Reusable UI sections
lib/data.js   → Centralized content and data
public/       → Images and static assets
```
